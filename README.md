## Skills

- **[Project Truth Keeper](skills/project-truth-keeper/SKILL.md):** recover current project truth, identify competing documents, and protect dirty work.

Each folder has a portable `SKILL.md`. Copy a skill folder into your client's supported skills directory and read its instructions. Optional Python helpers and tests are included as simple local tooling. No Docker, Railway, or GPU is required.
